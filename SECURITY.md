# Security policy

Sohva TV stores IPTV and API credentials locally and handles URLs that may
contain account information. Please report suspected credential disclosure,
unsafe URL logging, backup weaknesses, exported-component issues, or other
security problems privately to
[hello@luontra.fi](mailto:hello@luontra.fi).

Include the affected Sohva TV version, Android TV version, and reproduction
steps. Do not send working provider credentials, playlist files, exported
backups, or unrelated device data. Replace sensitive values with fictional
examples.

The current supported line is the latest numbered beta release. There is no
guaranteed response or remediation time while the project remains a personal
beta, but credible reports will be reviewed before public disclosure.
