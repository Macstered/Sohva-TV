# Sohva TV beta

Sohva TV is a remote-controlled media player for Android TV and Google TV,
with Live TV, Movies, Series and the optional Sohva Sport section.

**Current tester build: 0.1.0-beta.1 (build 2).** This is an early,
non-commercial test build, not a stable release. It contains no subscriptions,
channels, playlists or developer API keys. Bring your own authorized sources.

## Download and get started

Use the signed **`sohva-tv-0.1.0-beta.1.apk`** supplied with this package.
In the public distribution repository, open **Releases**, select the explicitly
numbered beta, and download its `.apk` asset. GitHub's automatically generated
"Source code" ZIP contains only these instructions; it is not the app.

Help and private issue reports: [hello@luontra.fi](mailto:hello@luontra.fi).

bug report. A public issue is visible to everyone.
